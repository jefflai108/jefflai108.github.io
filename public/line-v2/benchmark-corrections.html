這次基準測試修正了什麼

Interaction tasks Delegation tasks 台灣用語

第一批擴充測試發現 v2 + follow-up 的實驗包裝程式有缺陷，因此停止該批次，保留原始紀錄，修正後重新收集完整五版本資料。本頁是測試說明，不是第四個比較分頁，也不預先宣稱新一輪的成績。

為什麼重測

舊批次停在 332 筆互動紀錄：324 筆正常返回、8 筆降級。這是執行狀態，並不等於任務完成率或 API 呼叫數。當時執行中的工作先正常完成，才停止收集；委派與台灣用語題組尚未開始。

兩個缺陷會讓比較失真：

  • 群組被擋在模型呼叫之前。 Character 實驗版本沿用了「只支援私訊」的限制，收到群組訊息就回報 benchmark_private_scope_required。這不能拿來評斷模型的群聊能力。
  • 選擇不接話，也可能清掉使用者要求的貼圖。 舊提示要求 rest 時貼圖意圖為空，解析器又會在接話留白時清除貼圖。S004 的舊回執是解析後資料，沒有保留原始模型提議；無法確定當次模型原本有沒有選貼圖，但可以確認程式存在這條抑制路徑。

舊答案、失敗、時間與雜湊完整保留。v1 自己漏送貼圖的觀察也沒有被改寫；沒有只替換某個版本或某幾題的較差答案。

修正範圍刻意保守

Character 只有在外加的私訊記憶與主題資料皆為空時，才走原有 v2 群組流程；有私人資料仍在呼叫模型前拒絕。既有來源、隱私與群友身分檢查保留，私訊流程不變，也沒有套入 v3「只有真正標註麻吉才回覆」的政策。

貼圖只在合法直接回答、沒有澄清需求、有效且留白的 rest、主機允許貼圖、當前使用者明確要求全部成立後，保留原生目錄驗證過的意圖。無效接話、委派、否定或引用內容不會因此獲得貼圖。沒有新增模型呼叫、強迫選工具，或繞過貼圖頻率與傳送檢查。

另有顯示修正：純模型互動若只是缺少原生副作用快照，會另列「原生副作用未量測」，保留原本的部分通過判定；它不是工具失敗，也不是副作用安全通過。真正失敗與其他未評估結果仍可查看。

已驗證的部分，以及仍保留的限制

106 項聚焦離線檢查通過，涵蓋群組隱私、單次模型呼叫、實際貼圖傳送與歷史版本控制。這個總數已包含相關子測試，不重複加總。

R8 再以真實模型做一個獨立的 v2 + follow-up 小型驗證：14 筆正常返回，14 筆通用工具檢查通過。其中 11 個被舊政策接收的群組回合，各有一次成功的 Gemini 呼叫；另兩個回合沿用舊版忽略行為。加上 S004，共 12 次前景 HTTP 請求，沒有執行腦呼叫。

  • S004 確實送出慶祝貼圖，位於兩段文字之間；但該次接話不為空，因此不能用它證明 rest 分支已運作。接話內容是否自然仍是品質評審的問題。
  • G013 才是有效 rest 的實測證據：接話為空、貼圖意圖保留，捕捉到對指定群友的原生 textV2 標註，以及實際 LINE 鼓勵貼圖訊息。這不只是模型說「要送貼圖」。

通用工具通過不等於群聊契約全過。R8 原始群聊判定仍是 5 通過、5 部分、3 未通過：兩個舊版忽略回合沒有保存原文；一個回合多標註了未要求的群友；部分 v3 專屬安靜／接收檢查不適用舊架構。這些差異沒有被改成全數通過。

原生傳送證據來自本機捕捉的實際 LINE 訊息格式，並不代表已驗證真實手機收到通知。R8 是單一版本的開發驗證，不是五版本最終評比。

新的最終比較怎麼做

替代批次使用新的儲存目錄與同一份凍結程式碼，重新量測 69 題互動、75 題委派、35 題台灣用語 × 5 版本，共 895 筆。不從舊批次複製答案或延遲，也不挑選前幾輪中最好的一次。

新資料必須獨立完成收集與審查，才納入三個比較分頁；本頁不預填分數、延遲排名或改善幅度。被停止的舊批次、R8 開發資料與新最終研究各自保存。
