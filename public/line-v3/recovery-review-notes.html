快取、失敗文案與仍有限制的功能

GPT 執行腦：10 次 run、22 次模型請求，回報 238,581 個快取 token 的 run aggregate；沒有逐請求命中率。Gemini 執行腦：10 次 run、22 次完成請求、289,373 個 prompt token；其中 1 次明確回報 16,285 個快取 token，21 次缺少快取欄位。16,285 是觀測下限，完整快取總量仍未知，缺值不是零。

兩個 v3 在這批都沒有出現「我收到了。這次我整理得比較慢，我們可以接著聊」；v2 與 v2＋follow-up 各出現三次。沒有舊文案不等於任務全部完成。實際委派也驗證一般承接訊息已縮短為「好，我幫你處理一下 👀」。

R019 仍暴露真實能力限制：兩個 v3 的 read_link 收到 multiple_urls，兩頁都未讀取，沒有完成比較。R021 的內網拒讀文案正確，但本組原始檢查沒有完整網路側證，因此保留「未評估」，不以一句拒絕冒充網路隔離證明。

本組的 attachment_observations 是模型實際回傳的有界觀察，綁定實際送入介面的附件雜湊；不是獨立 OCR、工具回執或評審已看過的像素。收集後新增的 OpenAI 連結追蹤參數清理另列於 PR；不回改這批已生成答案，也不宣稱這批量測過該變更。
