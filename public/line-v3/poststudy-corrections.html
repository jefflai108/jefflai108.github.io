四項修正，各自的範圍

  • 缺 PDF 時的不必要委派：延用有限的缺附件宿主判斷，保留真正要求上傳檔案的澄清；不只依模型提到工具或文件的字詞就開始無用的執行工作。既有附件、獨立任務、副作用及待續操作仍需走原本的保護路徑。

  • 公開頁的輸入證據標示：前景快照是在主機呼叫前重建；只有本列有實際前景 HTTP 傳送嘗試才展示為前景主機輸入快照。這不是獨立捕捉的完整封包，也不證明模型收到資料；零 HTTP 的宿主拒絕不標成模型輸入。執行腦介面資料、工具回執及原始分數仍分開。
